# 學測翻譯 93-115 年互動格子拆分

用途：這份是給第二階段拖拉格子使用的結構拆分；逐字語法說明仍保留在 `exam-93-115-word-breakdown.md`。

分類：句首導入 / 句間連接、主幹、子句包（noun / adj clause）、黏著修飾（adj / adv）、補充細節（adv phrase / prep + N）。若有兩個完整分句，主幹會拆成 A 句與 B 句。

子句包只標名詞子句與形容詞子句：名詞子句通常整段當受詞或補語；形容詞子句通常整段修飾前面的名詞。副詞子句若只是時間、條件、讓步，仍放在句首導入或補充細節。

補充細節也可能是不定詞目的（to V）、分詞構句（V-ing / p.p. phrase）或子句（when / while / if...），重點是它補整句背景、目的、原因、結果或情境。

## 93 年

### 93-1
中文：雖然 Lily 生來又瞎又聾，但她從來不氣餒。

英文：Although Lily was born blind and deaf, she has never been discouraged.

- 句首導入 / 全句框架
  - 讓步：雖然 Lily 生來又瞎又聾
- 主幹
  - 主詞：她
  - 動詞：從來沒有
  - 受詞：氣餒
- 黏著修飾（adj / adv）
  - 無
- 補充細節（adv phrase / prep + N）
  - 無

### 93-2
中文：她的故事證明了，我們只要努力必能成功。

英文：Her story proves that as long as we strive, success is achievable.

- 主幹
  - 主詞：她的故事
  - 動詞：證明
  - 受詞：努力必能成功
- 子句包（noun / adj clause）
  - 名詞子句：that as long as we strive, success is achievable
  - 功能：整段當 proves 的受詞內容；as long as we strive 是子句內的條件
- 黏著修飾（adj / adv）
  - 無
- 補充細節（adv phrase / prep + N）
  - 條件：只要努力
