# 學測翻譯 93-115 年逐字語法拆解

格式：`英文單字(詞性 / 句中功能 / 中文對應)`。標點不列入逐字拆解；連字號單字如 `High-Speed` 視為一個詞。

## 93 年

### 93-1
中文：雖然 Lily 生來又瞎又聾，但她從來不氣餒。

英文：Although Lily was born blind and deaf, she has never been discouraged.

逐字：Although(連接詞 / 讓步子句引導詞 / 雖然) Lily(專有名詞 / 讓步子句主詞 / Lily) was(be 動詞 / 被動結構助動詞，過去式 / 被、生來) born(過去分詞 / 出生狀態核心 / 生來) blind(形容詞 / 主詞補語 / 瞎的) and(連接詞 / 連接兩個形容詞 / 和) deaf(形容詞 / 主詞補語 / 聾的) she(代名詞 / 主句主詞 / 她) has(助動詞 / 現在完成式助動詞 / 已經) never(副詞 / 否定頻率 / 從來不) been(be 動詞過去分詞 / 完成式被動助動詞 / 被、處於) discouraged(過去分詞 / 主句補語或被動核心 / 氣餒的)。

句型：Although + 子句, S + has never been + p.p./adj.

### 93-2
中文：她的故事證明了，我們只要努力必能成功。

英文：Her story proves that as long as we strive, success is achievable.

逐字：Her(所有格代名詞 / 修飾 story / 她的) story(名詞 / 主句主詞 / 故事) proves(動詞 / 主句動詞 / 證明) that(連接詞 / 名詞子句引導詞 / 這件事) as(連接詞片語一部分 / 條件引導 / 只要) long(連接詞片語一部分 / 條件引導 / 只要) as(連接詞片語一部分 / 條件引導 / 只要) we(代名詞 / 條件子句主詞 / 我們) strive(動詞 / 條件子句動詞 / 努力) success(名詞 / that 子句主詞 / 成功) is(be 動詞 / 連綴動詞 / 是) achievable(形容詞 / 主詞補語 / 可達成的)。

句型：S + proves that + as long as + S + V, S + be + C.
